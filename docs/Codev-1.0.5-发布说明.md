# Codev 1.0.5

- 文件树删除改为进入系统回收站，误删可恢复；并强化各主题下的选中态，降低父子同时删除的风险。
- 设置按钮左侧增加更新提示：默认可每 4 小时检查 GitHub 新版本，网络失败静默等待下次检查。发现新版本时以淡绿色显示「有新版本可用（v当前 → v最新）」，悬停查看发行说明，点击打开对应 Release 页。设置中可关闭或调整检查间隔。
- JSON 格式化对格式错误、文本截断给出异常提示。
- Pi 冷启动支持压缩；仅新增模型资源时不再误触发 runtime 重启。
- Pi / Codex 图片支持右键复制，点击非图片区域即可关闭预览。
- 修复 Pi 会话历史偶发无法上滚。
- 修复 Pi / Codex 多视口在空白窗口点击，或 Ctrl+点击尚未启动的新线程标题时页面崩塌。
- 多视口改为顺序占位：已占用窗口不会被点击抢走，关闭后才释放；拖入历史对话需确认后才会切换。
- 终轮交付后侧栏圆点改为蓝色待查看，点击后恢复默认灰色。
- Pi / Codex 增加 subagent 可视化，运行与完成状态可感知。
- 修复 Codex 线程归档与删除；已结束线程在切换资源时不再误报任务仍在运行。
- Codex 排队消息改为与 Pi 一致的简约图标操作。

## 下载

- Codev-1.0.5-Windows-x64-Setup.exe
- Codev-1.0.5-Windows-x64-Portable.exe

Codex 功能需要本机安装 Codex CLI 并配置可用资源；Pi 功能需要安装 Pi Coding Agent。便携版与安装版保持独立应用标识。

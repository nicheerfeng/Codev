# Codev 0.9.4

本次更新修复 Pi Agent 离线用量和模型显示名，并打通文件树自动刷新与 Pi 侧栏排序。

## Pi Agent

- 未激活的历史线程也能显示上下文占比，按模型窗口计算百分比。
- 会话里的 provider 对不上时，按模型 id 回退匹配窗口。
- 设置页改完 `models.json` 后，输入框立即使用新的显示名。
- 压缩提示在下一轮真正发送后自动消失。
- 项目和 session 支持 pointer 拖拽排序，重启后保留顺序，归档项不参与拖拽。
- 单击项目名可折叠，拖过阈值后才开始排序。

## 文件树

- 外部新增、复制、重命名和删除会自动出现在已加载目录中，不必再点父目录刷新。

## 二、第二期目标界面

### 1. 语言

新安装默认使用中文，已有用户保留已保存的语言值。本期只修改 `DEFAULT_PREFERENCES.locale` 的默认值，不扩展语言状态、翻译表和窗口同步逻辑；代码语言名、路径、Shell 命令和用户文件内容保留原文。

### 2. 文件树与 Workspace

左侧只保留工作区文件树：顶部显示 `工作区`、添加项目按钮和必要的搜索入口；主体显示用户加入的项目根目录；底部不再显示文件名、Windows Local、WSL 或路径面包屑。

启动状态应满足：`workspaceRoots = []` 时左侧显示空状态，不枚举 C:/、D:/ 或其他盘符，不自动把启动目录加入 Workspace。项目只能通过“添加项目”路径选择/输入或文件树目录右键“添加到工作区”进入；多个绝对路径以多个根目录并存，移除只改变 Workspace 配置，不操作磁盘文件。

同一棵文件树支持按住 Ctrl（macOS 为 ⌘）左键连续选择多个文件或目录；普通左键继续执行原来的打开/展开行为。右键已选项时保留整组选择，菜单中的“复制路径”一次复制全部绝对路径，每行一条；右键未选项时先将其设为当前选择。

右键行为统一为：

- 目录项：打开、在终端中打开、添加到工作区、重命名/新建、复制路径、删除。
- 当前浏览根目录标题和空白区域：提供“添加到工作区”和刷新。
- 已加入的根目录：显示项目名与完整路径提示，右键只提供从工作区移除等 Workspace 操作。

`fs_list_drives` 和盘符快捷浏览从默认 UI 移除。升级迁移仅清理旧版本自动产生的裸盘符根（如 `C:/`、`D:/`），保留用户明确添加的项目目录；整个过程不删除文件。

### 3. 顶部 Header 与设置

保留左侧栏切换按钮，它是文件树的必要入口；移除截图中 `⌘` 命令面板可见按钮及其占位。快捷键配置页面和键盘行为暂时保留，避免把“入口按钮”误删成“快捷键系统”。

设置齿轮固定在 Header 左侧动作区，直接替换原 `⌘` 入口；右侧不再重复显示设置按钮。设置页 General 只保留外观、语言、界面缩放和文件树显示隐藏文件；移除 WSL 发行版、Workspace environment、Shell 枚举及复杂终端监测配置。终端重命名、创建、关闭和切换放在终端面板内完成。

### 4. 终端面板

右侧终端改为“终端导航树 + 当前终端内容”布局：左窄列纵向显示终端条目，右侧保留当前 PTY/pane 内容。每个条目显示用户名称，第二行显示当前工作目录；默认名称使用工作目录末段，用户重命名后固定使用 `customTitle`，目录变化不覆盖用户名称。

终端条目支持单击切换、双击或右键内联重命名、创建、关闭；重命名支持 Enter 提交、Escape 取消、空值恢复默认名。已有 `TerminalTab.customTitle`、`labelFor`、`onRename`、`TerminalStack` 和 pane tree 继续复用，第二期不改变 PTY 生命周期和分屏模型。

### 5. Tauri 右键菜单

在主窗口根层增加 WebView 原生 `contextmenu` 拦截：普通 Header、顶部标签、面板空白区域禁止浏览器菜单；带有 `data-slot="context-menu-trigger"` 的 Radix 自定义菜单继续放行。输入框保留复制、粘贴所需的基础交互。

验收重点是：右键任意顶部标签不再出现保存、刷新、更多工具；右键文件、目录、搜索结果和标签仍能打开 Codev 自己的菜单，且不会出现两个菜单叠加。

### 6. 搜索

搜索入口必须显示清晰的范围和结果状态：

| 入口 | 目标 | 第二期行为 |
|---|---|---|
| Header 搜索 | 当前编辑器或当前终端内查找 | 显示匹配计数、无匹配状态、Enter 上下一个；占位文案不再泛化为工作区搜索 |
| 文件树搜索 | 文件名/目录名 | 调用 `fs_search`，默认搜索当前项目；无项目时显示“请先添加项目”，异常显示可见错误和重试 |
| 命令面板 `#` | 文件内容 | 调用 `fs_grep_interactive`，返回项目名、相对路径、行号和文本；多项目模式下按根目录聚合结果 |

文件名搜索的最小查询长度、加载状态、无匹配状态、截断提示和打开结果必须可见。后端调用失败不能只写 `console.error` 后清空列表；前端必须保留错误状态。第一版默认当前项目，后续可用“全部项目”范围复用同一搜索服务，不另造搜索引擎。

## 四、删除与保留清单

### 本期确认删除或移出界面的内容

- `src/modules/statusbar/StatusBar.tsx`、`WorkspaceEnvSelector.tsx`、`CwdBreadcrumb.tsx` 及无引用出口。
- `FileExplorer` 中 `fs_list_drives`、盘符条和仅用于盘符浏览的默认 UI。
- `GeneralSection` 中 WSL、Workspace environment、Shell 枚举和终端管理区；相关 setting 字段仅保留兼容读取，本期已不再进入界面，后续在引用归零时再删存储字段。
- Header 中可见的 `CommandIcon` 快捷入口及其布局占位。
- 仅用于单选视觉状态的文件树逻辑；保留普通点击打开/展开行为，新增多选状态与批量复制路径。
- 仅服务于上述旧 UI 的 WSL 状态标签、底部路径展示和无引用的适配代码。

### 需要继续保留的核心

- `RootTree`、`useFileTree`、`useWorkspaceRoots` 和多根目录持久化。
- CodeMirror 编辑器、Markdown 阅读、语法高亮、xterm PTY、pane tree 和终端会话生命周期。
- 自定义 Radix 右键菜单、文件操作、复制路径、在终端中打开。
- 快捷键执行层与设置页快捷键配置；本期仅移除可见的冗余按钮。
- `fs_search`、`fs_grep_interactive` 后端能力；先修正入口、参数和反馈，再决定是否继续删减。

## 五、验收闸门与范围边界

每个阶段只验证本阶段改动和直接依赖，避免借机重写稳定模块。至少覆盖：空 Workspace、两个异地项目、右键加入/移除、Ctrl/⌘ 多选并复制路径、中文默认、终端重命名、顶部原生右键、三种搜索结果和便携版启动。

本期不引入 LSP、语法检查、插件系统、代码补全、网页预览、远程项目、后台监控或新的状态管理框架。终端布局改造只触及导航与命名显示，PTY、分屏、会话清理逻辑沿用当前实现。

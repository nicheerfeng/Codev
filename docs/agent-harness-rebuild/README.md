## 当前架构

```text
Codev 右侧 Agent 界面       手机浏览器
          │                    │
          └── 已认证 WebSocket ─┘
                       │
             Rust Agent Host
              ├─ 会话与运行实例
              ├─ 有序事件、增量消息与快照
              ├─ 请求去重、队列与审批
              ├─ 原生历史索引
              └─ 元数据与设备授权
                       │
                ┌──────┴──────┐
           Pi 原生进程       独立 ACP 代理
```

运行状态由 Rust 管理。桌面和手机只持有展示副本。关闭视口或手机页面不会停止代理；停止任务、断开代理与退出主机是不同操作。

## 桌面审核

1. 使用审核窗口右侧的 **Agent** 标签；若未开启，在设置的插件页打开 **Agent 工作区**。
2. 选择工作目录，在顶部选择新会话使用的代理，然后新建会话。
3. Pi 使用本机原生程序、配置和认证。模型列表在原生进程连接完成后返回，不读取另一份界面模型目录。
4. 其他代理独立运行。代理设置中可以查看和修改启动程序与逐行参数；不会把它们的模型注册进 Pi。
5. 首次建议新建一个 Pi 会话进行人工反馈，避免与安装版或外部命令行同时操作同一份历史。

项目侧栏在右侧，可拖动分隔线调整宽度。多视口最多六格，按住标题移动六像素后开始交换内容，Escape 取消。关闭视口只影响布局。

Pi 分叉采用原生 `clone`，保留当前最后一轮；新分叉在确认生成独立原生文件前保持只读。较旧 Pi 不支持该命令时会报告错误，不会回退为丢弃末轮的行为。

## 手机连接

1. 桌面 Agent 页右上角打开 **代理与手机设置 → 手机连接**。
2. 主动开启手机连接，默认端口为 `7331`。关闭时只监听本机。
3. 生成一次性配对码，手机扫描二维码，在手机填写电脑显示的六位验证码。
4. 在电脑的待处理设备列表批准请求。手机取得自己的设备令牌。
5. 后续在该浏览器直接打开同一地址即可连接。撤销设备授权后，该设备不能继续访问。

二维码地址应为手机能够访问的电脑局域网地址。如果自动探测到的是不通的网卡地址，可在桌面配对卡片中修改主机地址。

当前手机页面支持项目和会话选择、文本与能力允许的图片、流式消息、队列、停止、审批、原生模型与思考等级选择，以及绑定工作区内的只读文本链接预览。远程设备不能安装代理、修改启动命令、添加任意工作目录或调用任意 Tauri 命令。

局域网入口使用 HTTP；公网访问需要另行配置 HTTPS 入口或安全隧道。本次不自动部署公网中继、端口转发或证书。

## 独立服务

先构建前端，再使用同一份 Rust 主机启动服务：

```powershell
pnpm build
pnpm cargo run --bin codev-server -- --host 127.0.0.1 --port 3080 --workspace "D:/your-project"
```

需要局域网访问时显式使用 `--host 0.0.0.0`。浏览器打开服务地址，在手机页面选择“使用独立服务器令牌”，填写服务控制台输出的令牌。

支持：

- `--host`：默认 `127.0.0.1`。
- `--port`：默认 `3080`。
- `--workspace`：可重复传入工作目录。
- `--data-dir`：指定主机元数据目录。
- `CODEV_WEB_DIR`：指定包含 `mobile.html` 和构建资源的目录。
- `CODEV_DATA_DIR`：独立服务默认数据目录的环境变量覆盖。

默认前端产物为仓库中的 `dist-agent-host/`，部署独立二进制时需同时提供该 Web 资源目录，或放在可执行文件旁的 `web/`。桌面安装包通过 Tauri 资源映射携带 Web 目录。独立服务复用主机代码，不依赖某个桌面窗口转发请求。

## 历史与兼容边界

- Pi：只读扫描原生 JSONL，按父链读取当前分支，展示分段历史；续聊由 Pi 原生启动参数恢复。
- Codex：可以发现原生历史，当前以只读方式展示。不会把原生 Codex 文件标识直接冒充 ACP 会话标识。
- 旧 Antigravity：读取旧应用存储中的项目、标题和原生会话绑定；能否恢复由代理实际 `loadSession` 能力和执行结果决定。
- 自定义 ACP：只有代理明确支持恢复并实际回放历史时，才能承诺恢复对话展示。没有历史能力的代理不通过伪造消息补齐。
- SQLite：只保存工作区、会话绑定、配置偏好与设备令牌哈希；不替换原生历史，也不保存模型认证。

## 旧目录处理

用户授权暂时不删除文件。当前系统同时拒绝删除与重命名，因此旧源目录原位保留，但已从入口、依赖图、类型检查、代码检查和测试入口中隔离。旧 Rust 模块不再注册，旧插件不再出现在界面中。

重构前完整核心备份仍位于 `D:/software/CodexScope-dev111`。不要为清理隔离目录而结束安装版 Codev 或删除用户的命令行配置。

## 本轮验证边界

本轮仅执行类型检查、编译、构建和静态诊断，不主动发送模型提示词，不运行业务测试，不自动操作用户已有会话。原生 Pi/ACP 的真实回复、审批、手机网络与设备联调由用户通过审核窗口反馈。

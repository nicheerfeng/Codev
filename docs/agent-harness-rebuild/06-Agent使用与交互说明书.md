# 06 — Codev Agent 工作区使用与交互说明书

> 本说明书对应**已完成 Phase 1–4 优化升级后的当前版本实际代码行为**。如果你之前觉得 Agent 界面信息混乱或不清楚怎么操作，可以直接按本手册逐区使用。

---

## 一、快速上手：打开 Agent 与接入项目

1. **确认开启**：在 Codev 设置 -> 插件中开启 **“Agent 工作区”**（`agent-host`）。
2. **把项目送进工作区（手动按需缓存）**：
   - 初始启动**只加载你手动添加或明确导入的工作区缓存记忆**（存储于 SQLite），不会自动扫描全机历史目录或把后台文件树目录直接灌满侧栏；
   - 在左侧资源管理器中右键文件夹 -> **“添加到 Agent 工作区”**（完成后自动展开工作区）；
   - 或在 Agent 右侧边栏点击 **`＋`** 手动添加工作目录；
   - 若需要召回过往 Pi / Codex 原生会话，点击侧栏顶部 **`↻`** 手动扫描并按需勾选导入。
3. **认识界面布局**：
   - **顶部标题栏**：左侧是**新建会话区**，中间是**当前选中会话的所属代理与标题**，右侧是会话动作、并行视口计数与设置/侧栏开关。
   - **左侧主区域（1–6 格视口）**：同时并行运行和查看多个 Agent 会话。
   - **右侧边栏**：管理工作区、历史会话、置顶/归档与历史导入。

---

## 二、三大内置代理（Harness）与区别

Codev 坚持 **“原生归原生、外部归外部”**，不同代理各自运行独立进程，互不混用模型：

| 代理名称 | 底层协议与来源 | 适用场景 | 认证与准备方式 | 关键边界说明 |
| :--- | :--- | :--- | :--- | :--- |
| **Pi (`pi`)** | 原生 RPC（`pi --mode rpc`） | 日常编码主力、多分支探索、原生工具链、技能与扩展 | 使用 `~/.pi/agent`（或 `PI_CODING_AGENT_DIR`）配置与模型 | 支持逐字增量流式、上下文占用明细与压缩、按消息节点分叉、`steer` 实时插队。 |
| **Codex (`acp:codex`)** | ACP 桥接（优先本地托管 `codex-acp`，支持自定义） | 使用 OpenAI Codex 代理能力 | 终端已登录 Codex（`codex login` 或 `OPENAI_API_KEY`）且具备 Node.js | **外部历史 vs 新会话**：从 `~/.codex/sessions` 扫描导入的旧日志完整保留对话/思考/工具调用与时间，但按只读展示；**新建的 Codex 会话**可正常交互。 |
| **Antigravity (`acp:antigravity`)** | ACP 桥接（`agy acp --stdio`） | 调用 Antigravity（`agy`）代理 | 安装 `agy` CLI 并在终端完成 Google 登录 | 若终端能运行 `agy` 而 GUI 未定位，可在设置 -> `代理与诊断` 查看路径检测或填写完整路径。 |
| **自定义 ACP** | 用户填写的 stdio ACP 命令 | 接入其他兼容 Agent Client Protocol 的工具 | 在设置 -> `代理与诊断` 点击 `添加自定义 ACP 代理` | 支持随时修改或点击 `删除` 移除自定义配置。 |

## 三、顶部栏操作说明

1. **新建区域（最左侧）**：
   - **`新建` + 代理下拉框**：这里的下拉框**仅决定点击 `新建` 时使用哪个代理**；点击侧栏已有会话不会改变那条会话的底层代理。
2. **当前会话图标与状态（中间）**：
   - 以对应的 **Harness 图标**（悬停显示 `Pi` / `Codex` / `Antigravity` 等及只读状态）、所属工作区名与会话标题清晰区分当前线程，避免冗长分类文本占空间。
3. **动作与布局按钮（右侧）**：
   - **`连接` / `重连`**：空闲会话可按需唤醒或重启底层代理进程。
   - **`克隆分支`**：基于当前活跃分支克隆出一条新会话继续实验（仅支持分支的代理显示）。
   - **视口数量 `- N/6 +`**：调整同时并排展示的会话格子数量（1–6 格，关闭格子不会中断后台代理运行；布局会自动持久化）。
   - **设置图标 / 侧栏开关**：打开代理设置与诊断弹窗，或折叠/展开会话侧栏。

## 四、右侧会话侧栏：排序、拖入视口与历史导入

- **工作区（项目）列表**：
  - 点击项目标题前的 **`▾` / `▸`** 可独立展开或折叠多个项目，互不挤压。
  - 若某项目下有任务正在执行，项目行右侧会显示 **运行中计数角标**；按住项目名上下拖动（指针捕获，兼容原生文件拖放）可调整项目顺序。
  - 点击项目右侧 `＋` 可在该项目下直接新建会话；点击 `⋯` 可 **在目录中显示**、**复制路径** 或 **从工作区移除**（绝不删除磁盘代码）。
- **单条会话操作**：
  - 左侧状态点显示运行/未读态，紧跟所属 **Harness 图标**（Pi / Codex / Antigravity / 其他 ACP 等），不再堆砌文字分类名，鼠标悬停可查看完整代理类型与只读说明。
  - **拖拽**：按住会话行上下拖动可调整显示顺序；直接拖到主区的某个视口格上即可放入该格并行查看。
  - **原地重命名**：双击会话标题或选中后按 `F2` 即可改名（多视口格子标题同样支持双击 / `F2` 改名与拖拽互换）。
  - **右键 / `⋯` 菜单**：`重命名`、`置顶/取消置顶`、`归档/恢复到列表`、`导出 Markdown`、`断开/强制断开代理进程`、`从列表移除`（仅从 Codev 列表移除索引，保留磁盘原生历史文件）。
- **两步式历史扫描导入（`↻`）**：
  - 点击侧栏顶部的 `↻` 后先只读扫描本机 Pi / Codex 历史，在预览弹窗中按需勾选后导入，避免一次性塞满侧栏。

## 五、对话阅读区：看懂工具、Diff、计划与审批

1. **Turn 级过程时间线与紧凑实时微滚动**：
   - 同一用户回合内的 **思考、工具调用（读取/搜索/命令/修改）与中间过渡叙述** 会统一收拢进 **1 个竖线时间线过程块**，仅将最后完成的正式答复独立干净展示；不再在每次思考或过渡语处切出多个零散卡片。
   - **运行态紧凑微滚动视窗**：发送任务后立即出现状态与计时；在未手动展开时，过程头下方会呈现 **2~3 行紧凑微滚动视窗**，以自下而上的平滑切入动画实时滚动最近推进的步骤（思考预览、命令、目标文件等），点击可随时展开完整时间线。
   - **完成后收拢单行精华**：回合结束自动收敛为单行精华摘要（如 `已完成 · 读取 2 · 命令 3 · 变更 1 文件 · 用时 19秒`），点击标题或搜索命中即可展开回顾。
   - **探索合并与状态标识**：
     - 连续的读取文件、搜索、列目录步骤会被合并为紧凑的 `探索 N 项`；
     - 文件修改类工具（`edit` / `write` / `apply_patch` / ACP Diff）内联显示红绿行对比与 `+adds / -dels` 统计，点 **`在编辑器对比`** 可配合主区 **Git / Diff 模块**打开完整差异标签；
     - 终端命令实时预览尾部输出；针对 `grep` / `rg` 找不到内容的退出码 `1`，显示为中性 **`无匹配`** 而非红色报错；
     - 先前同类步骤失败后又由后续步骤走通的，会标记 **`已恢复`**；
     - 原始底层 JSON 参数与完整输出收在“查看原始参数与输出”折叠项内按需查看。
2. **回合级文件变更与 Git Diff 联动**：
   - 每个发生过文件写入/修改/新增/删除的 Turn 结束后，下方直接附带汇总的 `TurnFileChangesBar`（显示该轮影响的文件列表及 `+adds / -dels`）；点击即可直接打开编辑器 Diff 对比或预览文件，点 `↗` 在系统资源管理器中定位。
3. **计划卡片与审批请求**：
   - ACP `plan` 渲染为可勾选状态的进度清单（并在对话顶部显示当前进行中计划条）。
   - 需要权限或交互输入时出现结构化请求卡，标注作用域（`工作区内文件写入` / `代理工具权限` / `扩展交互请求`）、目标路径/命令详情，并将拒绝/取消设为安全默认焦点。
4. **消息交互、搜索与跳转轨**：
   - 正文开头的 `<think>...</think>` 会自动拆进 `思考过程` 折叠区；图片支持点击放大灯箱；表格支持一键复制为 Markdown。
   - 每条消息底部可查看时间、`复制`、助手回复一键 `朗读 / 停止朗读`；支持真分叉的 Pi 用户消息点击 **`分叉`** 可精确从该消息节点分出新分支。
   - 在激活会话中按 **`Ctrl+F`（Mac `Cmd+F`）** 或点右上 `搜索` 可检索正文、思考、工具名与调用参数，上下跳转时会自动展开所在折叠块；对话超过 4 轮后右侧会出现 **数字回合跳转导航轨**。

## 六、输入区：命令、文件联想、附件与精细队列

1. **高度控制与技能高亮**：
   - 按住输入框**最顶边向上拖拽**可自由调整编辑区高度，并按会话记住高度、光标和滚动位置；输入的 `$skill` 会自动高亮识别。
2. **`/` 命令与 `@` 文件联想**：
   - 输入 `/` 自动在上方弹出命令候选，合并了本地快捷操作（`/compact`、`/fork`、`/new`、`/stop`）与当前代理命令，使用 `↑ / ↓ / Tab / Enter / Esc` 选择；对偏交互式的终端命令会标出 `建议终端执行`。
   - 输入 `@` + 关键词自动模糊检索当前工作区文件与目录，回车选中后直接挂成关联文件芯片。
3. **图片与文件拖放**：
   - 可从资源管理器或系统桌面直接拖拽文件/目录到任意视口的输入区：**图片**自动读取为缩略图附件（单条最多 4 张，前端单张限制 3.5 MiB），**文件与目录**生成干净的芯片标签随消息附带发送，不再向文本框塞入长串路径文字；也支持 `Ctrl+V` 直接粘贴截图。
4. **排队与立即插队（Queue & Steer）**：
   - 当代理正在回复时：按 `Enter` 会将新消息加入待发送队列；按 **`Ctrl+Enter`（Mac `Cmd+Enter`）** 则触发 **`插队（Steer）`**。
   - 队列列表中支持对任意一条点击 **`插队`**、**`编辑`**、**`↑` 上移**、**`×` 删除** 或 **`清空队列`**。
5. **模型、参数胶囊与上下文环**：
   - 底部带有明确标签的胶囊控件可调节 **模型**、**思考等级** 与各类代理运行配置；若修改需要重连才生效会给出清晰提示。
   - 右下角的 **环形上下文图标** 可点击打开明细浮层，查看累计 Token、模型上限、`Input / Output / Cache` 分布，以及触发/查看 `压缩上下文` 的耗时与更新状态。

## 七、设置面板（4 个标签页）与手机远程连接

点击顶栏设置图标可配置以下 4 个部分：

1. **`代理与诊断`**：
   - 点击 **`重新自检`** 对 Pi / Codex / Antigravity 及自定义 ACP 做真实环境诊断，直接告诉你处于 `就绪`、`未定位程序`、`需模型配置` 还是 `需命令行登录`，并展示实际定位到的可执行路径与解决建议；
   - 可为 ACP 代理单独设置 **ACP 宿主写文件策略**（`每次询问确认（推荐）` / `允许直接写入工作区` / `禁止代理写文件`）；
   - 支持内置代理 **`恢复默认`**、自定义 ACP 添加与 **`删除`**。
2. **`规则与通知`**：
   - 控制 **回合结束系统桌面通知**（窗口未聚焦或最小化时提醒）；
   - 管理当前工作区 `.pi/extensions` 项目级扩展信任开关；
   - 查看或编辑 Pi 全局系统指令 `~/.pi/agent/APPEND_SYSTEM.md`（附 `models.json` 已配置 Provider 概览）与 Codex `~/.codex/AGENTS.md`。
3. **`手机连接`**：
   - 开启局域网监听端口后生成二维码和 **6 位一次性配对码**，并在桌面批准/撤销设备；
   - 手机浏览器初次连接即便尚无打开会话也会看到明确的会话列表与新建引导；若桌面端短暂离线，手机端会保留本地设备令牌并提供重试；独立命令行服务端 `codev-server` 可保持长连接不断开。
4. **`语音`**：
   - 配置语音转文字（ASR）及语音合成（TTS）参数。

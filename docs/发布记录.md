# Codev 发布记录

> 所有正式版本和待发版变更集中记录于此。创建 GitHub Release 时，优先从对应版本条目复制说明，避免遗漏修复范围、验证结果和交付文件。

## 记录格式

每个版本固定记录：

- 版本与标签：`Codev x.y.z` / `vx.y.z`
- 发布日期：使用 `YYYY-MM-DD`
- 变更摘要：用户可感知的功能和修复
- 兼容性说明：数据、配置、系统或升级注意事项
- 验证结果：类型检查、测试、构建和实际烟测
- 交付文件：正式文件名、平台和 SHA-256
- 已知问题：只记录未阻断发布的事项

## Release 使用流程

1. 完成开发后，将“待发版”改为正式版本条目。
2. 补录测试命令、构建产物、SHA-256 和已知问题。
3. 将该版本条目的“变更摘要”和“兼容性说明”用于 GitHub Release 描述。
4. 发布后保留 Git 提交、标签和最终资产名称，下一轮重新建立新的“待发版”条目。

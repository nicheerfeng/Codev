# Codev 1.2.0

审核状态：待人类审核。本文为本地构建说明，审核前不作为对外更新提示。

## 统一 Agent 工作区

- 整合原有分散的 Pi 与 Codex 插件为统一 Agent 宿主，原生支持 **Pi**、**Codex (ACP)** 与 **Antigravity (ACP)** 三类代理，共用同一套多视口工作区、消息队列、附件拖拽、分支感知与历史管理。
- 最多支持 6 视口并发，新增自动追加视口，视口标题支持拖拽互换，保持会话挂载不中断。
- 统一对话操作栏：消息下方提供图标化的复制（带对勾反馈）、按需语音朗读（仅在开启语音播放时显示）、会话分叉与终轮撤回重编辑；运行态终止按钮恢复为实心方块配合柔和呼吸动效。
- 补齐 Pi 扩展实时状态条（输入框正上方显示沙箱模式、MCP、LSP、飞书等扩展状态）与冷启动历史输入上翻（打开历史会话后直接按上方向键即可回溯历史输入）。
- 精简 Agent 设置界面：左侧仅保留「代理（Pi / Codex / Antigravity）」与「工作区 → 通用（偏好 / 语音 / 手机连接）」；各代理顶部支持一键开关项目栏新建快捷入口；Codex 运行环境显示真实 `codex-acp` 路径与本机 Codex CLI 路径。

## 跨网手机远程控制（Tailscale）

- 「手机连接」支持自动探测本机 Tailscale 虚拟网络（`100.64.0.0/10`）并展示实时通道状态，无需手动配置安装路径，开启后即可跨网端到端加密直连手机端控制页。
- 自动过滤代理软件虚拟网卡干扰地址，入口区分「Tailscale 加密入口」与「本机预览」，并新增「使用说明」与「清空配置」一键重置能力。

## 记事本升级（块级 Markdown 待办 + SQLite）

- 记事本底层升级至 SQLite 结构化存储，支持行内 Markdown 渲染（粗体、行内代码、删除线、可点击链接、`#标签` 与多行备注）、项目与已完成项折叠、完成进度条与两行截断悬停预览。
- 新增软删除回收站（支持撤销、恢复、彻底清除）以及 Markdown 源码视图、JSON/Markdown 导入与 `.md` 导出。

## 界面体验与文件工作流

- **左右布局一键镜像**：Dock 顶栏右侧新增布局切换按钮，可在「左文件树 + 右 Agent」与「左 Agent + 右文件树」之间一键切换，Agent 内部项目栏同步镜像。
- **全局统一悬浮提示**：新增全局托管 Tooltip 引擎接管原生 `title`，统一适配玻璃感、VSCode 质感与传统黑白主题，彻底消除系统白底提示框的割裂感。
- **注意力优先视觉规范**：全局开关采用低饱和莫兰迪雾蓝 + 清晰描边层次，主设置窗口与 Agent 设置弹窗统一采用克制的中性边框风格；紧凑化右下角 Toast 通知。
- **文件树增强**：新增非阻塞增量扫描「属性」弹窗、原地复制文件夹、支持透明删除 Windows 保留名文件（如 `nul`）并移入回收站；优化多显示器跨 DPI 拖拽适配与标签栏「关闭左侧 / 关闭全部」操作。

## 本地构建产物

- Codev-1.2.0-Windows-x64-Portable.exe

Codex 功能需要本机安装 Codex CLI 并配置可用资源；Pi 功能需要安装 Pi Coding Agent；Antigravity 功能需要本机安装 `agy` CLI。便携版与安装版保持独立应用标识。

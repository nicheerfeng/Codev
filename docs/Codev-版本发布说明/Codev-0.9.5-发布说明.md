# Codev 0.9.5

起始体验：

- 新增首次进入的欢迎页，说明 Codev 遵循「人类注意力优先」，面向 agentic 业务生产的工作台定位。
- 进入工作区后自动落成文件树 / 阅读器 / 终端三栏默认布局，不必再手动调整分栏。
- 覆盖安装后会再次显示欢迎页；便携版与安装版各自独立记录，互不影响。
- 文件树根目录默认收起，并分别记住每个根目录的展开状态；新加入的根目录不会自动铺开。
- Pi 侧栏的项目与分组折叠状态会被记住，新出现的项目默认收起。

Pi Agent：

- 新增「临时聊天」分组，直接使用 Pi 主目录作为工作目录，不必先添加项目即可开始对话。
- 统一线程身份，修复同一会话在侧栏出现重复「新线程」的情况。
- 修复模型选择与运行中会话配置不一致的问题：运行中的任务不会被打断，空闲线程在下次发送时自动适配当前模型配置。
- 会话没有历史模型记录时，模型选择回落当前可用模型列表，不再显示为空。
- 扩展的通知不再占用输入框上方的提示位。

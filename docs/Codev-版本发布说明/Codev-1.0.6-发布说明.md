# Codev 1.0.6

- 修复 Codex 上下文压缩感知，改为独立压缩态，不再误显示为普通运行中。
- 修复 Codex 资源热切换误报后台任务，空闲线程结束后可正常切换。
- 修复对话输入区无法点击终止的问题。
- Pi / Codex 设置增加自定义提示词管理，保存后对后续会话生效。
- 修复 Pi 运行中只改 API Key 不重建 runtime 的问题。
- 输入框恢复 Ctrl+Z 撤销。
- 队列消息支持显示图片，图片会压缩后显示在文本前。
- 终端、Pi、Codex 多开窗口支持放大视口，并可一键缩回原分组。
- 修复动态思维切换在执行中卡住的问题。
- 修复二次编辑区域出现大量空白的问题。
- 修复强制终止后切换模型仍沿用旧模型的问题。
- 优化 GPT-6 思维链为空时的显示。
- 左侧文件树根目录改为仅图标显色，不再整行铺色。

## 下载

- Codev-1.0.6-Windows-x64-Setup.exe
- Codev-1.0.6-Windows-x64-Portable.exe

Codex 功能需要本机安装 Codex CLI 并配置可用资源；Pi 功能需要安装 Pi Coding Agent。便携版与安装版保持独立应用标识。

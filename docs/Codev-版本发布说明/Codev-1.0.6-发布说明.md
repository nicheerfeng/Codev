# Codev 1.0.6

- 修复 Codex 切换资源时误报无法读取 `auth.json`，资源密钥改由原生配置管理。
- 修复初始配置缺失及旧资源记录与当前配置混用；优化 Pi 会话尾部编辑后的历史保持。

- 修复 Codex 删除线程时可能长时间等待，并优化 Codex 插件页面的初始化流程。
- Pi / Codex 项目支持通过右键菜单添加到左侧文件树，可选择“添加到工作区”或“在工作区中打开”。
- 修复文件夹侧边栏重复配色和异常红色，恢复统一、克制的项目身份色规范。
- 修复运行中中断后错误切换模型的问题，改为复用当前已有 runtime。
- 修复长 JSONL 关键词定位，支持定位到关键词所在行并保留特殊关键词的精确高亮。
- 修复 Pi / Codex 多开窗口的高度缩放，双行视口可正确扩展至整行。
- 修复 PDF 阅读器使用的 PDF.js 版本问题，恢复稳定的 PDF 加载与搜索能力。
- 修复 Pi / Codex 待处理队列消息显示，支持队列中的图片预览与正常保留。
- 修复 Codex 右侧线程运行感知态，使线程运行状态与主视口的执行过程保持同步。
- 修复 Codex 上下文压缩感知，改为独立压缩态，不再误显示为普通运行中。
- 修复对话输入区无法点击终止的问题。
- Pi / Codex 设置增加自定义提示词管理，保存后对后续会话生效。
- 修复 Pi 运行中只改 API Key 不重建 runtime 的问题。
- 输入框恢复 Ctrl+Z 撤销。
- 终端、Pi、Codex 多开窗口支持放大视口，并可一键缩回原分组。
- 修复动态思维切换在执行中卡住、二次编辑区域出现大量空白的问题。
- 修复强制终止后切换模型仍沿用旧模型的问题。
- 优化 GPT-6 思维链为空时的显示。
- 左侧文件树根目录改为仅图标显色，不再整行铺色。

## 下载

- Codev-1.0.6-Windows-x64-Setup.exe
- Codev-1.0.6-Windows-x64-Portable.exe

Codex 功能需要本机安装 Codex CLI 并配置可用资源；Pi 功能需要安装 Pi Coding Agent。便携版与安装版保持独立应用标识。

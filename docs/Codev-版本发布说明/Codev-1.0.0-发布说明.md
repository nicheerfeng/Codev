# Codev 1.0.0

把本地文件真正接到 Pi Agent 上。

- 左侧文件树可以直接拖到右侧 Pi 输入区：图片仍作为图片发送，其他文件和文件夹变成路径标签。
- Pi 观测到的修改文件，点击即可在阅读区打开，不必先加入工作区根目录。
- 资源管理器里的任意文件也可以直接拖进 Pi 界面。
- 对话里对人只显示文件名标签，发给模型的仍是完整本地路径。

这一步向 Visual Studio Code 和 Codex 致敬。2025 年下半年，VS Code 已经把本地文件拖进 Agent 对话做成日常动作；Codex 则把「改完就能看」练得更顺。Codev 1.0 是向它们学习后的落地。

## 下载

- Codev-1.0.0-Windows-x64-Portable.exe

# Codev 0.9.7

这是一次集中消化存量问题的版本，覆盖大文件阅读、Pi Agent 运行态，以及关窗口后的后台感知。

阅读：

- 大体积 JSONL 改为按行短预览滚动，长字段不再把横向滚动条拉到无限长；选中一行复制仍是完整记录。
- PDF 内部外链改到系统浏览器打开，不再把 Codev 主视口带跑。
- Markdown 与 Pi 对话里的表格一键复制为 Markdown，不再弹出 CSV / TSV 菜单。
- Pi 设置增加版本页：上面看本机 Codev 和 GitHub 更新，下面看 Pi CLI 仓库进展。
- 关闭窗口进入托盘，Pi 在后台跑完会弹出 Windows 通知；托盘右键可真正退出。

Pi Agent：

- 运行中插入消息走原生插入和排队，不再被当成新一轮发送。
- 归档后重启不再弹回原列表。
- 折叠的项目只要还有线程在跑，标题会带运行蓝点和轻微呼吸。
- 「项目」右侧改为左新建组、右添加项目，组图标不再像添加子项目。
- 插件列表会扫描 settings 里的 packages 和 extensions，不再漏项。
- 上下文自动压缩成功后会继续刚才的任务，而不是停在空闲。
- 新建和分叉线程出现在该组列表顶部；打开线程会钉在对话底部，而不是停在中部。

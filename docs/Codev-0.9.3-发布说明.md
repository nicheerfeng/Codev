# Codev 0.9.3

本次更新优化 Pi Agent 会话恢复与队列操作，并完善文档阅读和标签关闭体验。

## Pi Agent
- Pi Agent 大幅度提升了与 agent 对话的交互使用体验，包括但不限于：
  - 引入与 Codex 风格类似的极简注意力压缩信息展示机制，引入运行时感知、脚本压缩展示等。
- 浏览历史、修改模型与思考等级、重命名及分叉时，未运行的会话不再启动 Pi 进程。
- 长会话默认加载最近 150 条消息，上翻继续加载更早记录，并保持阅读位置。
- 修复空闲进程回收后再次发送时的整页加载遮罩，保留已有对话，持续显示运行状态与耗时。
- 排队消息支持退回编辑、删除和立即引导当前任务；退回编辑时保留已有草稿。
- 运行蓝点增加旋转外环；用户消息气泡靠右、随内容收缩，最大宽度为内容区的 80%。
- 新增服务商默认提供 name，公共配置与服务商标题双向同步，保存时使用对应名称。

## 阅读与标签
- 主阅读区新增 Codev 风格右键菜单：可编辑文本支持剪切、复制、粘贴，只读渲染区支持选区复制。
- 禁用 Windows 原生浏览器右键菜单，避免误触刷新等浏览器操作；HTML 预览使用 Codev 复制菜单。
- Rendered / Raw 切换按钮左移，为右侧滚动条留出空间。
- 修复“关闭右侧标签”遗漏跨项目文件的问题，按所选标题在当前标签栏中的位置关闭右侧全部标签，保留自身与其他分屏。
- 批量关闭前自动保存已修改的目标文件；保存失败时保留标签并提示原因。

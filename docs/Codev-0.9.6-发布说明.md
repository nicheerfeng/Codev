# Codev 0.9.6

阅读与预览：

- 修复 HTML 阅览中的相对图片、大体积 Pi 导出黑屏，以及标题点击误跳进 Codev 的问题。
- 切标签后记住阅读位置，Markdown 与代码文件会回到上次滚到的地方。
- 点击图片可全屏阅读，支持滚轮放大和拖动画幅；Pi 输入区、对话附件和工作区图片共用同一套预览。

Pi Agent：

- 模型选择器按当前模型高亮，同名模型也能分清；思考等级弹出列表不再被底部输入区裁切。
- 侧栏线程位置更稳定：组内拖拽排序、默认展示 5 条、一次展开 50 条。
- 右键仍用对话框重命名，双击标题可就地改名。
- 消息的时间、复制、编辑、分叉改到气泡下方，避免挡住单行输入；最后一条已完成的助手回复可复制和分叉。

## 下载

- Codev-0.9.6-Windows-x64-Setup.exe
- Codev-0.9.6-Windows-x64-Portable.exe

Pi 功能需要本机安装 Pi Coding Agent 并配置可用模型。便携版与安装版保持独立应用标识。

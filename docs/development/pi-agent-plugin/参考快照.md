## 采用与排除

- 采用：Pi 官方 RPC 命令和事件语义、原生会话文件、React 消息展示模式、明确的运行/终止/错误状态。
- 选择性移植：消息卡片、工具调用折叠、输入区、模型与思考等级选择、会话列表布局。
- 排除：完整 Web 服务、远程登录、文件管理器、内置终端、Git 工作树、移动端、通知、插件市场和多 Agent daemon。

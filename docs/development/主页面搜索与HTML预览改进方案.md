# 主页面搜索与 HTML 预览调整

2026-09-20；以用户最新反馈为准，替换此前已撤销的静态预览方案。

## 文件搜索

- 单根目录，默认包含隐藏和生成目录；名称、相对路径及空格分词匹配。
- 后台渐进返回，旧查询取消；结果滚动加载，命中文件夹在结果内逐层展开。
- 删除底部统计和解释。扫描发现第 200001 个文件时停止，才显示：
  当前搜索范围过大>20W文件，目前搜索结果无法搜全，如需请使用everything之类的软件来定位搜索
- 目录不计入文件预算；恰好 200000 个文件不显示上述提示。
- 保留本轮已有根目录右键“在文件管理器中显示”入口。

# 界面状态存储

界面布局统一写入 Tauri 应用数据目录下的 `codev-ui-state.json`。Windows 安装版为 `%APPDATA%/app.teague.codev/`，便携版为 `%APPDATA%/app.teague.codev.portable/`，沿用各自独立配置的规则。

保存范围：包含终端的 Dock 标签顺序、左右栏宽度与折叠、文件树目录展开与根目录折叠、Pi 项目与组折叠、首次布局及欢迎完成标记。启动时先加载文件再挂载界面，后续变更立即更新内存并串行落盘。

旧 localStorage 中的上述键会在文件缺项时自动迁移。迁移后文件为唯一写入来源，旧浏览器数据不覆盖已有文件值。标签顺序始终包含已关闭的插件，重新启用后恢复原位置。

安装戳变化不再触发欢迎流程和三栏重置。保留应用数据的覆盖安装会继续使用原布局；删除应用数据后的全新安装按默认值初始化。

其他状态继续按职责存储：`codev-plugins.json` 保存插件开关及 Pi 组织和模型偏好；工作区与常规偏好保留原生存储。主题/背景的 localStorage 是首屏配色缓存，命令面板 MRU 是使用频率缓存，均不属于布局，不迁入布局文件。Pi 原生会话及凭据不迁移。

此次同时修正 Pi 折叠恢复时序：等项目、会话和组织数据就绪再初始化折叠集合，避免异步加载把上次展开的项目当作新项目重新折叠。

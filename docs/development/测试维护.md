# 测试维护

日常改动使用 `pnpm test:changed` 按 Git 改动与依赖关系运行相关测试；正式发版使用 `pnpm test` 和 `pnpm check-types`，涉及 Pi 界面时运行专项浏览器回归。

1.0.2 删除 15 项仅匹配源码文本的测试：TextDiffPane 9 项、JsonFormatterPane 2 项、MarkdownPreviewPane 4 项。这些测试锁定变量名、组件写法和 CSS 类，无法验证实际交互，容易妨碍等价重构。文本差异计算和 JSON/JSONL 解析行为测试继续保留。

会话隔离、停止与队列、终端输入与生命周期、文件操作、状态迁移等行为测试继续保留。测试是否有效按能够发现的真实回归判断，不按总数量或删减比例判断。新增界面测试优先覆盖真实操作结果，避免以源码正则替代交互核验。

# Codev 1.0.1

让 Pi 的过程看得清，让终端回到该在的位置。

- Pi Agent 主动停止后，最后一条输入可以原位编辑并重新发送；原图片保留，底部草稿不被覆盖。
- 思考与工具执行按阶段收纳，摘要直接展示真实思考片段、工具原名和调用参数；展开后按时间查看单行记录，点击才显示完整详情。
- 思考预览从开头显示，超长内容在末尾省略；状态切换增加轻量过渡，流式文字追加不会反复闪动。
- 修改观测与过程摘要对齐；折叠正文按需渲染，搜索仍可定位并展开内容。
- Pi 完成通知带上线程名称与结果摘要，运行中追加任务的“下一步／随后”提示更清晰。
- 修复终端日志输出时的底部跟随，统一滚动条外观；上翻查看历史时保留阅读位置。
- 修复从其他插件切回终端后出现大块空白的问题，隐藏期间保持有效网格尺寸。
- Codev 与 Pi 的版本检查分开显示；Pi 插件页补充已安装清单与公开包快捷安装。
- 修复拖动选中文字时误触发文件拖入的问题，保留正常文件和图片拖拽。

## 下载

- Codev-1.0.1-Windows-x64-Portable.exe

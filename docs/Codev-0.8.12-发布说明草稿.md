# Codev 0.8.12

本次更新新增 Pi Agent 工作台，并改善 Markdown 双栏阅读体验。

## Pi Agent 工作台

- Pi 作为独立插件启用，与终端、JSON 格式化、文本对照共用工具区域。
- 线程侧栏位于右侧，支持按项目分组、新建组、重命名、归档、导出和确认删除；可拖动调整宽度。搜索、设置与侧栏折叠入口集中在顶部左侧。
- 多线程独立运行，切换时保留草稿和状态；思考过程与工具调用按轮次聚合，历史加载显示等待动画。
- 发送后自动跟随最新消息，主动向上翻阅暂停跟随；搜索支持关键词高亮和定位，通知与错误按线程隔离。
- 消息支持复制与时间显示，最后一条输入可停止后取回编辑；未执行的排队文字可恢复到输入框。
- 一键分叉生成完整新线程并自动编号；输入框支持 `/compact` 手动压缩、`/fork` 和 Pi 扩展命令，方向键选择自动滚动跟随。

## 模型管理

- 进入插件提前加载当前项目模型，减少点击模型菜单后的等待。
- 设置提供侧栏导航、顶部服务商列表和三列等高 JSON 卡片；支持新增、复制、重命名、确认删除及单卡保存，Ctrl+S 仅保存当前卡片。
- 使用说明通过独立模态展示，包含服务商、模型清单和 JSON 示例。
- 支持单模型及全部已保存模型测试，显示状态和耗时；临时测试不写入会话历史，关闭设置会取消未完成测试。
- 直接读写 Pi 原生 models.json；不增加备份、重新加载、全局保存或独立服务入口。

## Markdown 阅读

- 修复 Markdown “在侧边打开”后无法切换渲染视图的问题。
- 设置增加新打开文件的默认渲染／原文模式，主阅览器、侧边阅览器及外部拖入统一使用该偏好。

## 一、原始需求(用户确认版)

1. **多文件夹导入**:保留文件树,支持多个文件夹(类似 VS Code 多根工作区),当前单窗口仅支持单文件夹。
2. **核心功能集**:项目文件树 + 文件阅览 + 多终端 + 中英文切换。
3. **模块裁剪**:去除 source-control / git-history / agents / ai(含 model 配置)/ control / updater 等与核心需求无关的模块。
4. **一键唤醒终端**:右键点击任意文件或文件夹 → 在右侧终端面板打开对应路径终端(文件取父目录)。
5. **终端面板布局**:终端从顶部 tab 体系剥离,独立停靠在文件阅览器右侧,可水平放置多个终端(不抢占顶部文件名空间)。
6. **去除 vim 模式**。
7. **修复 D 盘/盘符导航 bug**(无法选择 D 盘、配置入口难找)。
8. **中英文切换**(i18n,仅核心 UI 优先)。

## 三、关键架构决策(新接手必读)

1. **多根模型**:roots 存在 **preferences store(全局)**,非 per-space(与原始规划文档中"扩展 spaces"的设想不同,实际实现更简单可控,后续可平滑迁移到 per-space)。
2. **终端面板**:不改 useTabs 的 tab 模型,terminal tab 仍是 tab,只是**视图层拆分**——Header/TabBar 与 WorkspaceSurface 只渲染 fileTabs,TerminalPanel 渲染 terminalTabs。spaces 序列化天然兼容。
3. **react-resizable-panels v4 语法**:Panel 用 `panelRef`(非 ref)+ `PanelImperativeHandle`(collapse/expand/isCollapsed);Group 用 `orientation`(非 direction)。
4. **pnpm 生态**,不用 npm/yarn;路径一律 `@/`。
5. **质量闸门**:`pnpm lint` / `pnpm check-types` / `pnpm test`;Rust:`cargo clippy --all-targets --locked -- -D warnings` + `cargo test --locked`。
